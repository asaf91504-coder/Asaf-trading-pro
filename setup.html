איך מעלים את ASAF TRADING PRO לרשת?

קוד האתר כבר נמצא ב-GitHub. כדי שהשינויים יופיעו באתר Netlify הקיים, צריך לחבר פעם אחת את המאגר אליו. את האישור לחשבון Netlify יכול לתת רק בעל החשבון.

שלב 1 — חיבור האתר הקיים ל-GitHub

  1. פתח את Netlify והתחבר.
  2. בחר בפרויקט הקיים joyful-seahorse-967889 (כדי לא ליצור אתר חדש).
  3. פתח Project configuration → Developer settings → Continuous deployment → Repository.
  4. לחץ Link repository, בחר GitHub, ואז את asaf91504-del/Asaf-trading-pro בענף main.
  5. אם GitHub לא מציג את המאגר, פתח את הגדרות הגישה של Netlify GitHub App והוסף אותו לרשימת המאגרים המאושרים.
  6. הגדרת פרסום: Publish directory: .. הגדרת פונקציות כבר נמצאת ב-netlify.toml. אשר Deploy.

שלב 2 — בדיקת הגרסה החינמית

  1. פתח את האתר: joyful-seahorse-967889.netlify.app.
  2. לחץ 🩺 בדוק אתר ושרת. אם הבדיקה מצליחה, Netlify פרס את פונקציית הבריאות.
  3. פתח מניה בגרף, העלה CSV ובחר 📸 צלם את הגרף ונתח.
  4. ודא שהצ'אט מציג את תאריך הנר האחרון ואת המקור, ולא טוען למידע חי שלא נבדק.

הגרסה הזאת אינה מפעילה OpenAI בתשלום או API שוק חיצוני. היא מנתחת CSV במכשיר.

שלב 3 — נתוני שוק אוטומטיים (אופציונלי בלבד)

אל תפעיל את השלב הזה בלי לבדוק רישיון שימוש ועלויות. Twelve Data Basic אינו מעניק באופן אוטומטי רישיון להצגת נתונים. ייתכן שנדרש מסלול מתאים או ספק אחר. נתונים בזמן אמת מכל הבורסות אינם מובטחים בחינם.

רק כאשר ברשותך נתונים מורשים ותנאי שימוש מתאימים, ניתן להגדיר את המשתנים הבאים ב-Netlify, בצד השרת בלבד:

  • TWELVE_DATA_API_KEY — מפתח ספק פרטי
  • ASAF_MARKET_ACCESS_CODE — סיסמה פרטית של 20+ תווים
  • ASAF_MARKET_ALLOWED_SYMBOLS — סימולים מאושרים, כגון AAPL,NVDA
  • ASAF_MARKET_DISPLAY_LICENSE_CONFIRMED=true — רק לאחר אימות הזכות להציג נתונים
  • ASAF_MARKET_ENABLED=true — הפעלה מפורשת

המערכת אינה כוללת מכסת שימוש גלובלית קשיחה ולכן אינה מוכנה לשימוש ציבורי עם ספק נתונים. קוד הגישה לבדו אינו מספק הגנה על תקציב או על רישוי נתונים.

אבטחת AI בתשלום

הצ'אט באתר משתמש כברירת מחדל בנוסחאות ונתונים מקומיים. אין צורך במפתח OpenAI. פונקציית ה-AI הישנה נשארת כבויה כל עוד ASAF_CHAT_ENABLED אינו מוגדר כ-true. אל תפעיל אותה בלי אימות משתמשים, מכסות שרת ותקציב מוגן. לעולם אל תשתף מפתחות API בתוך צ'אט, צילום מסך או קוד.
