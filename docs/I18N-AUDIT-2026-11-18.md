# Translation repair and acceptance audit — 2026-11-18

## Findings

The English scanner screenshots contained Hebrew sentences with individual English
words substituted. New UI messages were missing from the original catalogs and
fell through to word-by-word substitution. This was reproduced on the live site.

## Changes

- Added full-sentence translations for current scanner, chart/search, account,
  chat status, support and research UI across all nine non-Hebrew locales.
- Added full-message templates so dynamic counts, dates and tickers keep their
  position without translating pieces of an otherwise untranslated sentence.
- Exact matches also handle surrounding whitespace. English enum labels are
  translated only as exact labels, not arbitrary words inside provider prose.
- Search/install dialogs inherit the active language direction.
- Subscription dates are rerendered in the selected locale without another billing
  request. Saved conversation titles are preserved as user-authored text.
- Support and approved-setup pages use the same persistent language selector.

## Acceptance coverage

Each of he, en, es, ar, fr, de, pt, ru, zh and ja has its own acceptance test.
The tests cover dynamic UI, direction, placeholders, draft preservation and
switching away/back. A second set of ten scanner regression tests covers the
actual screenshot sentences, empty results, counts, progress, completed scans,
asset search counts and chart timestamps. Catalog key and placeholder parity is
checked separately.

Live browser validation and final suite results are recorded below when complete.
This is interface localization, not a translation service for user-authored chat,
company names, source articles or external provider content. No provider rights,
billing, quotas or data access have been changed.
